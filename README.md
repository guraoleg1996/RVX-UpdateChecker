# ☑️ RVX UpdateChecker

## 🇺🇸 English

**RVX UpdateChecker** is a simple, non-commercial, fan-made Android application designed to compare your installed ReVanced apps with the latest releases on the website https://rvx.to/

### ✨ Features

* **Version Comparison:** Automatically compares installed app versions with the latest releases on the website https://rvx.to/
* **Pull-to-Refresh:** Instantly updates information by swiping down.
* **AMOLED Mode:** Pure black theme option to save battery on AMOLED displays.
* **Multi-Language Support:** Full support for English and Russian interfaces.
* **Easy Navigation:** Quick access to settings and links for updates (the app redirects to the site and does not download files directly).

## 🇷🇺 Русский

**RVX UpdateChecker** — это простое некоммерческое фанатское Android-приложение, предназначенное для сравнения установленных приложений ReVanced с последними релизами на сайте https://rvx.to/

### ✨ Особенности

* **Сравнение версий:** Автоматически сравнивает установленные версии приложений с последними релизами на сайте https://rvx.to/
* **Обновление свайпом (Pull-to-Refresh):** Мгновенно обновляет информацию смахиванием вниз.
* **AMOLED-режим:** Опция чисто чёрной темы для экономии заряда на AMOLED-экранах.
* **Мультиязычность:** Полная поддержка английского и русского интерфейсов.
* **Удобная навигация:** Быстрый доступ к настройкам и ссылкам для обновлений (приложение перенаправляет на сайт и не скачивает файлы напрямую).
